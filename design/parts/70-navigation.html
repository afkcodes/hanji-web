Navigation

06

Navigation is chrome, and hanji keeps chrome plain — five equal tabs, a title that steps aside as you scroll, a bar that knows where you are — so the content gets the character. Every gesture here follows the finger first and the spring second.

    Search New

    A field that answers while you type: recent searches when it's empty, suggestions as letters arrive, and a way forward when nothing matches — never a dead end.

    Field
    44 · pill · surface · focus ring accent
    Rows
    52 · glyph by kind · match set in 700
    Recents
    5 max · each removable · Clear all
    Entrance
    cascade 24 ms, once per change of kind
    Empty
    says what was searched + a nearest match
    A11y
    combobox · ↑ ↓ Enter Esc

    Results cascade when the list changes kind (recent → suggestions → none), not on every keystroke — typing should feel instant. Removed rows fade; the rest close the gap on snappy.

    Pull to refresh New

    For feeds that change while you're away. The pull is the progress bar: the ring fills as you drag and tells you when letting go will work. Not for lists that update themselves.

    Threshold
    64 px of visible travel
    Resistance
    exponential · asymptote 160
    Ring
    28 · stroke 3 · accent on fg @ .10
    Hold
    56 px while working · gentle
    Arrival
    new row rises 12 · accent-soft fades
    Reduced
    ring holds still · says “Refreshing”

    The list hangs on a gentle spring while it works, then lets go. Crossing the line gives one small pulse — the visual twin of a haptic tick.
